# espn-client

An independently installable Zig 0.16 client for ESPN's public Site API. The
source in `src/generated.zig` is generated by openapi2zig and has no dependency
on the sprts server or its domain model.

```zig
.espn_client = .{ .path = "path/to/clients/espn" },
```

```zig
const espn = @import("espn_client");

var client = espn.Client.init(allocator, io, "");
defer client.deinit();
var result = try espn.getScoreboard(&client, "baseball", "mlb", "20260906", null, null, null);
defer result.deinit();
```

Run `mise run generate:espn` from the repository root to regenerate it. The
package includes the upstream YAML file and its normalized JSON copy. The
released generator reads the JSON copy, so generation does not need the server
package or another source checkout.
