# sprts-client

An independently installable Zig 0.16 client for our own sprts JSON API
(`/api/v1`). The source in `src/generated.zig` is generated by openapi2zig
from the live `/openapi.json` document (single source of truth:
`apps/server/src/spec.zig`) and has no dependency on the server or its
domain model.

```zig
.sprts_client = .{ .path = "path/to/clients/sprts" },
```

```zig
const sprts = @import("sprts_client");

var client = sprts.initClient(allocator, io);
defer client.deinit();
var result = try sprts.getScoreboard(&client, "mlb", "2026-09-06", null, null);
defer result.deinit();
```

## Regenerating

Unlike `clients/espn` (which checks in its upstream spec), there is NO
checked-in spec file here: the generator starts a local server, fetches
`/openapi.json` from it, and runs openapi2zig. From the repository root:

```sh
mise exec -- tools/generate-sprts-client
```

The script skips rewriting `src/generated.zig` when the generator checksum
is unchanged, and runs `zig fmt` on a fresh result.

Env overrides (same conventions as `tools/generate-espn-client`):

- `OPENAPI2ZIG` — generator binary (default `openapi2zig`, pinned 0.5.6).
- `SPRTS_OPENAPI_SPEC` — use this spec file instead of starting a server.
- `SPRTS_OPENAPI_BASE_URL` — `--base-url` passed to the generator
  (default `http://localhost:8080/api/v1`).
- `SPRTS_PORT` / `PORT` — port for the throwaway local server
  (default `8080`).

## Base URL

The wrapper defaults to production (`https://sprts.horv.co`, host only: the
generated paths already carry the `/api/v1` prefix). Override per client
with `withBaseUrl`; the CLI layer reads `SPRTS_BASE_URL` and applies it
there. Never hand-edit `src/generated.zig`.
